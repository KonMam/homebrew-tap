# homebrew-tap

Homebrew formulae and casks for [KonMam](https://github.com/KonMam)'s tools.

```bash
brew install KonMam/tap/venn
```

| Tool | What it is |
|---|---|
| [venn](https://github.com/KonMam/venn) | Row-level keyed diff of tabular datasets: files, directories and lake tables |

Casks here are published automatically by each project's release pipeline.
Report issues against the tool's own repository, not this one.
